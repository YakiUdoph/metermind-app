# Failure Detection and Recovery Matrix

This document maps all failure scenarios in MeterMind, their detection mechanisms, current/desired behaviors, and payment risk levels.

| Failure | Detection | Current Behavior | Desired Behavior | Automatic Recovery | Retry Policy | Fallback Option | Payment Risk | Status | Evidence |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Provider timeout** | AbortSignal after 8s | Returns `EXECUTION_TIMEOUT` status | Awaits response up to timeout limit, then throws | Yes, selects fallback candidate | Immediate selection of next ranked provider | Rotate to next candidate in competition set | None (occurs before payment) | `REAL_VERIFIED` | `coingecko.test.ts` |
| **Provider rate limit** | HTTP 429 status code | Returns `LIVE_PROVIDER_RATE_LIMITED` | Backs off and retries (future) or marks unavailable | Yes, selects fallback candidate | Rotate to next provider | Rotate to next provider in competition set | None (occurs before payment) | `REAL_VERIFIED` | `coingecko.test.ts` |
| **Provider malformed response** | JSON.parse catch blocks | Returns `LIVE_PROVIDER_BAD_RESPONSE` | Throws bad response and disqualifies provider | Yes, selects fallback candidate | Rotate to next provider | Rotate to next provider in competition set | None (occurs before payment) | `REAL_VERIFIED` | `coingecko.test.ts` |
| **Both providers unavailable** | Registry evaluation | Returns execution status `FAILED` | Return typed failure structure | No | None | Rejects task with `NO_PROVIDERS_FOR_SERVICE` | None | `REAL_VERIFIED` | `live-competition.test.ts` |
| **Quote disagreement** | Scorer checks price spreads | Returns `QUOTE_DISAGREEMENT` if > 5% | Intercept and reject execution | No | None | Disqualifies both/aborts execution | None | `REAL_VERIFIED` | `live-competition.test.ts` |
| **Quote expiry** | Policy checks quote timestamps | Policy guard checks limits at execution time | Reject execution if quote is stale | No | None | Aborts execution (requires manual request retry) | None | `PARTIAL` | `policy.ts` |
| **RPC timeout** | Promise.race 5s timeout | Rotates to fallback RPC url | Connects to secondary node | Yes, shifts provider connection | Rotates through rpcList | Fallback RPC (e.g. Thirdweb node) | None (occurs before payment signature) | `REAL_VERIFIED` | `rpc-fallback.test.ts` |
| **RPC wrong chain** | check network.chainId !== 48816 | Throws typed error `Unsupported chain ID` | Immediate halt, refuse to sign | No | None | Fails execution | None (aborts before signing) | `REAL_VERIFIED` | `rpc-fallback.test.ts` |
| **RPC unavailable** | try/catch connection error | Rotates to fallback RPC url; if all fail, throws | Rotates through list and throws if all are down | Yes, rotates through list | Rotates through rpcList | Rotate to fallback RPC | None (aborts before signing) | `REAL_VERIFIED` | `rpc-fallback.test.ts` |
| **Merchant unavailable** | HTTP fetch catch block | Returns `PAYMENT_SUBMISSION_FAILED` | Safe connection failure | No | None | Fails execution | None (occurs before payment) | `REAL_VERIFIED` | `payment.test.ts` |
| **Merchant disabled** | HTTP status code !== 402 | Returns `X402_CHALLENGE_INVALID` | Intercept and block signature | No | None | Fails execution | None (occurs before payment) | `REAL_VERIFIED` | `payment.test.ts` |
| **Insufficient gas** | `getWalletBalances` native balance check | Checks balances on RPC | Warn in UI and block signature | No | None | Block execution | None (occurs before payment) | `REAL_VERIFIED` | `wallet.ts` |
| **Insufficient token** | `getWalletBalances` token balance check | Checks USDC balances on RPC | Warn in UI and block signature | No | None | Block execution | None (occurs before payment) | `REAL_VERIFIED` | `wallet.ts` |
| **Payment timeout** | Polling loop status query | Retries status check 5 times; if unsettled, returns `UNKNOWN` | Await confirmation, flag if timeout | No | Status poll retry | Block delivery | None (value is on L2, but delivery is locked) | `REAL_VERIFIED` | `goat-client.ts` |
| **Payment uncertain** | `statusResult.status === 'created'` | PaymentResult set to status `FAILED` and `UNKNOWN` | Intercept and prevent retry with new tx | No | Status poll retry | Requires manual review of txHash | High (value transferred but delivery blocked) | `REAL_VERIFIED` | `goat-client.ts` |
| **Duplicate execution** | Idempotency guard check | Policy Guard returns `PAYMENT_ALREADY_SETTLED` | Rejects duplicate payment attempt | Yes, prevents duplicate pay | None (aborts immediately) | Fails execution with duplicate error | None (duplicate blocked) | `REAL_VERIFIED` | `payment.test.ts` |
| **Delivery failure** | HTTP status !== 200 on `/v1/deliver` | Returns `PAID_BUT_DELIVERY_FAILED` status | Compile complete payment audit trace | No | None | Fails execution; stores audit receipt for refund | High (value transferred but merchant failed) | `REAL_VERIFIED` | `payment.test.ts` |
| **Acceptance rejection** | Output schema/keyword checks | Returns `REJECTED` status | Block task success status | No | None | Fails execution; stores audit receipt for dispute | High (value transferred but output is bad) | `REAL_VERIFIED` | `contract.test.ts` |
